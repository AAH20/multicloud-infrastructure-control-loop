# Unit Economics

Version 0.1.0 calculates only incremental cloud-cost scenarios. It makes no ROI claim.

Each rule stores low, expected and high monthly assumptions. Logging estimates scale with the supplied monthly-event volume; other fixtures use fixed illustrative deltas. Results are deliberately marked low-confidence until validated against:

- provider pricing APIs or calculators;
- deployment region and service tier;
- measured request, traffic, storage and ingestion volumes;
- discounts, reservations and contractual commitments;
- operational labor, migration and rollback costs.

A production business case should separately record incident-loss assumptions, engineering hours, audit effort, change failure rate and opportunity cost. Savings must be reported as measured, modeled or hypothetical—not blended together.
